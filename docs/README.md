# Documentação e Apresentação

Coloque aqui os artefatos de entrega da sua equipe.

## Entregáveis esperados

| Arquivo | Descrição |
|---------|-----------|
| `presentation.*` | Slides ou documento para a apresentação final (PDF, PPTX, etc.) |
| `demo_video.*` | Link ou arquivo do vídeo demo de até 2 minutos (ou adicione o link no README principal) |
| [`architecture_engine.md`](architecture_engine.md) | Arquitetura do motor probatório, estimador de condenação e decisão financeira |
| [`DIVISAO_TRABALHO.md`](DIVISAO_TRABALHO.md) | Responsabilidades das três frentes e integração da equipe de cinco pessoas |

## Checklist de entrega

- [ ] Código-fonte na pasta `src/`
- [ ] `SETUP.md` preenchido com instruções de execução
- [ ] Apresentação nesta pasta (`docs/`)
- [ ] Link do vídeo demo adicionado ao README principal
- [ ] `.env.example` atualizado com todas as variáveis necessárias

## Arquitetura da solução

A arquitetura canônica está documentada em [`architecture_engine.md`](architecture_engine.md). Ela descreve o risco baseado em disponibilidade binária, a extração com fontes e a comparação financeira entre acordo e defesa. Não há validação documental nem cenários de contestação.
